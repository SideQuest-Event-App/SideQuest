# Context engineering Projects "our North Star is called X, which
we define as Y" look for "custom instructions" or the
system prompt. Ask us if you can't find it.*
## A starting template
```
You are building <product> for <who it's for>, competing with
<what it replaces>.
Positioning: <your one-sentence positioning statement>.
Our North Star is <name>, defined as <definition>.
It is a function of: <input A>, <input B>, <input C>.
Always design and write toward these. When a request conflicts
with them, say so.
```
## Do / don't
- **Do** keep it under a page that's Week 3).
- **Don't** re-type your strategy into every prompt. If you're
doing that, fix the instructions.
- **Don't** paste in feature lists or hedge language not the
prompt.
